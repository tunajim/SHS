Campus Wifi

Here at Washington State University, Vancouver, students have access to high-speed internet everywhere on campus. The preferred network for students and faculty will appear as WSU Wireless Crimson. Whether you are doing homework, taking an online class, or emailing a professor, you can count on having reliable internet access.

Troubleshooting Wifi

If you ever find that you are unable to connect to campus Wifi. There are several ways that we can restore access. The following steps often will resolve connectivity issues, but if you need more assistance, feel free to visit us in VCLS 223.

Steps to Restore Wifi Access

On occasion, you may find that you can no longer log into the network, use the following steps to troubleshoot access.

On Mac

  1. Open System Settings

    To easily get to System Settings, you can use the Spotlight Search (Command + Spacebar) and type in System Settings.

  2. Navigate to the Network tab

    The Network tab is located on the left hand side of the setting panel.

  3. Click Wifi tab

    At the top of the Network page, press the Wifi option.

  4. Find WSU Wireless Crimson under “Known Network”

    On the Wifi page, networks there will be a few labels indicating types of networks. The “Known Network” section, will display networks you are currently connected to.

  5. Press the 3 dot button on side of network

    The “WSU Wireless Crimson” option, will have a 3 dot menu button on its right hand side. Press the button to reveal more options.

  6. Forget the network

    Go ahead and press, “Forget This Network..” which will remove it from “Known Network”

  7. Rejoin WSU Wireless Crimson

    After forgetting the network, try to rejoin “WSU Wireless Crimson.” If you are still unable to join the network, click here to set up an appointment.

On PC

  1. Open Settings

    Click the Start button, then the Settings icon

  2. Navigate to "Network & Internet"

    There will be a menu option for "Network & Internet." Select this option.

  3. Select Wifi

    There will be an option for "Wifi" on the left-hand menu.

  4. Click on "Manage known networks"

    Find and click the option for "Manage known networks" and click the link

  5. Select and forget "WSU Wireless Crimson"

    Under known networks, you should see "WSU Wireless Crimson". Select the network and there will be a "Forget" option. Click this button.

  6. Rejoin "WSU Wireless Crimson"

    After forgetting the network, try to rejoin “WSU Wireless Crimson.” If you are still unable to join the network, click here to set up an appointment.
